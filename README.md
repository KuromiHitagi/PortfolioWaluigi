## 💜 Sobre o Projeto

Este projeto é a interface do meu portfólio pessoal, desenvolvida para combinar o universo retrô dos games com uma estrutura Web moderna, performática e interativa. A escolha do **Waluigi** traz uma paleta de cores roxo/rosa estilizada, detalhes marcantes e muita personalidade para apresentar minhas habilidades e projetos.

### 🌟 Destaques da Temática
* **Paleta WAH:** Tons de roxo profundo (`#051139`, `#21054e`), contrastes em rosa/magenta e detalhes em amarelo pastel.
* **Componentes Personalizados:** Carrossel de projetos, tabelas de serviços e seções interativas com elementos surpresa (Easter Eggs).
* **Animações CSS Customizadas:** Rotações, escala ao passar o mouse (*hover*) e carrossel de texto contínuo usando Keyframes nativos.

## 🎯 Arquitetura & Otimizações Técnicas

| Área | Implementação |
| :--- | :--- |
| **Estilização** | Organização com Variáveis CSS (`:root`) para trocas rápidas de temas e padrões de cores. |
| **Efeitos Visuais** | Animação contínua de texto na classe `.desc` com `@keyframes` e transições de escala dinâmicas. |
| **Layout Responsivo** | Flexbox para alinhamento fluído e adaptações para diferentes dimensões de tela. |
